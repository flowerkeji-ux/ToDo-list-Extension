# ToDo List Extension

A to-do list extension to keep track of tasks on your browser.

## What you can do 
1. add tasks
2. cancle tasks
3. cross tasks out- so you know what youve done
4. store tasks and info beacuse there is local storage

## How to use 
1. go to your chrome extensions
2. turn on developer mode
3. press load unpacked
4. upload this
